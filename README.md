# Interconnected Places — Progress Over People in Pittsburgh

This repository holds my spatial history project for the Interconnected Places Lab (HIST 1907). It maps one place and the places it was connected to.

## About this project

This project takes place in the Hill District during the era of urban renewal - the 50s up to the late 60s. It aims to map the displacement, urban decline, & population decline caused by projects like the highways & the Civic Arena, as well as the movement of people out of the neighborhood to other neighborhoods. My goal is to answer this question: how does large-scale clearing & development affect people, & does this type of development really outweigh the harms they caused?
## The files

- **`index(8).html`** — the interactive map. Your places are written inside this file, so this is the file you edit to make the map your own.
- **`README.md`** — this page (the front page of the repository on GitHub).

## How to view the map

- Open the folder in VS Code and use the **Live Server** extension (right-click `index.html` → *Open with Live Server*), or
- Turn on **GitHub Pages** (Settings → Pages → main branch) to get a public link anyone can visit.

## The place fields

Every place has three pieces of information, spelled exactly this way:

- **Name** — what the place is called
- **Date** — when it existed
- **Description** — one or two sentences of history
